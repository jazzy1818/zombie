Manual practice with the loaded extension

Load the repository's extension directory as an unpacked extension. Open DevTools, select the Browser Teacher console context, then run this recipe:

fetch('/docs/extension-practice.json')
  .then(response => response.json())
  .then(lesson => __BT_DEV.runLesson(lesson));

Follow the panel's instructions using the real website buttons. Stop or close the panel to cancel. A redirect clears the current lesson.
